# Vietnamese QCM Quiz

## Run locally
Open `index.html` in a browser.

## Publish with GitHub + Netlify
1. Create a GitHub repository.
2. Upload `index.html` (and this README if you like) to the repository root.
3. In Netlify, choose **Add new site → Import an existing project**.
4. Connect the GitHub repository.
5. Build command: leave blank. Publish directory: `.` (root).
6. Deploy the site.

## Quiz features
- Normal PDF order and random question order.
- Random mode also shuffles answer choices.
- Choose 10–150 questions or all available.
- Correct answer green; incorrect selected answer red.
- Mobile responsive.
- Score counts only questions with answer keys.

## Answer-key note
The supplied PDF has 35 listening questions and 24 reading questions, but no answer-key page. The reading answer choices were inferred from the reading passages. Listening answers are left unkeyed because the required audio/official key was not supplied. Review the inferred reading key before using this as an official exam.
